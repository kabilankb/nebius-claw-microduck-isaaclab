Why it matters

A day of sim-to-real work, turned into a conversation

Getting a walking policy from simulation onto a small robot normally means launching training, watching reward curves, guessing hyperparameters, exporting, converting, checking interfaces and hoping it doesn't fall off the table. Here an agent does the loop, and you approve the one step that moves real motors.

💬

Anyone can run it

Students, hackathon teams and robotics newcomers say what they want; the agent picks the task, settings and tools.

⚖️

It judges, not just runs

Policies are gated on fall rate, not reward alone. A failing policy resumes with gentler learning automatically.

👁️

It watches the gait

Nemotron 3.5 Super VL looks at frames from the rollout video and critiques how the duck actually walks.

🛡️

Safe for real hardware

9 sim-to-real checks on every policy, and the robot is never loaded until you say the duck is on its stand.

✅

Honest answers

Status replies are rendered from the real pipeline state and relayed verbatim — the agent can't invent progress.

💻

One laptop GPU

Your GPU only simulates. All the reasoning runs in the cloud on Token Factory, so no GPU memory goes to the LLM.

How it works

One request, the whole pipeline

The Duck pilot — a Hermes agent in its own NemoClaw sandbox — starts the pipeline on the host, reports on it, and stops at the one step a human must approve.

Train→ Gate · fall rate ≤ 25%→ Tune & retrain if it fails→ Play · video + ONNX→ Verify · 9 checks→ Deploy to the duck 
$ ./duck ship

Quick start

Run it yourself

Needs an NVIDIA GPU, Isaac Lab with the MicroDuck task, NemoClaw, and a Token Factory API key.

Start everything

echo "NEBIUS_API_KEY=<your key>" >> ~/.openclaw/.env
chmod 600 ~/.openclaw/.env

./demo.sh check   # key, model, GPU, ports
./demo.sh up      # → http://localhost:8800
./demo.sh down

Drive the duck from a terminal

./duck run -n 1500 --tries 2  # full pipeline
./duck ship                   # best checkpoint → robot
./duck watch                  # live status card
./duck deploy                 # asks: on its stand?
./duck chat                   # talk to the Duck pilot
